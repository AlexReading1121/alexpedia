# Alexpedia

Alex's magic knowledge library built with Quartz.

## Live Site
https://alexreading1121.github.io/alexpedia/

## Development

This is a Quartz-based static site generator.

### Build locally
```bash
npm install
npm run build
```

### Structure
- `wiki/` - Content directory
- `public/` - Built site output
- `quartz/` - Quartz configuration
